# Git Learning Project

A simple C++ console application used to practise Git and GitHub development workflows.

## Project Objectives

- Learn Git fundamentals and version control.
- Practise feature branches and Pull Requests.
- Understand commit history and merge conflicts.
- Develop good software engineering habits.

## Application Menu

The application currently displays the following options:

1. Start Application
2. Settings
3. GitHub Remote Synchronisation Test
4. About
5. Help
6. Exit

The menu options are currently placeholders for future functionality.

## Technologies

- C++
- Git
- GitHub
- Visual Studio Code

## Development Workflow

Changes are developed on feature branches before being merged into `main` through GitHub Pull Requests.
